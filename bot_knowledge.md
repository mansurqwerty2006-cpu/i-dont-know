# Локальная база знаний

Бот работает в Telegram через Groq API.

Если спрашивают, как бот устроен:
- пользователь пишет сообщение в Telegram;
- Python-скрипт получает сообщение через Telegram Bot API;
- скрипт отправляет вопрос в Groq Chat Completions API;
- Groq возвращает ответ модели;
- скрипт отправляет ответ обратно в Telegram.

Если спрашивают про постоянную работу:
- бот должен быть запущен на компьютере или VPS;
- для 24/7 лучше использовать VPS и systemd;
- на домашнем компьютере бот работает только пока компьютер включен, есть интернет и процесс Python не остановлен.

Если спрашивают про fine-tuning:
- настоящий fine-tuning меняет веса модели и требует датасет;
- в этой версии используется практичная настройка поведения: профиль, база знаний, few-shot примеры и постоянная память чата;
- Groq LoRA/fine-tuning может требовать отдельный доступ и заранее обученный адаптер.
